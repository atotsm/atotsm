# atotsm V3 — implementation notes

V3 is a conservative evolution of the supplied V2 working tree.

## Added
- An accessible, responsive connection map linking Usurology / the Sovereign Library, Arcadialogy / Ikigaiology, the Sovereign Laboratory and AIology.
- Social sharing metadata for title and description.
- Improved menu button semantics and an animated open state.
- Focus-visible styling and reduced-motion handling for the new connection cards.

## Preserved
- V2's narrative blueprint and terminology.
- The distinction between Usurpia and Arcadia as coexisting conditions.
- The mutual enrichment of Usurology and Arcadialogy / Ikigaiology.
- The existing worked example and its qualifications.
- The existing static-first architecture and all existing sections.

## Deliberately not added
- Invented contact details, payment destinations, publication links or project status claims.
- A framework, backend, analytics dependency or external JavaScript library.
- A forced membership or ideological conversion funnel.

## Before publishing
- Confirm the canonical GitHub repository and intended deployment branch.
- Add verified social image / favicon assets if desired.
- Replace support and contact placeholders only when real destinations are ready.
- Test on the target Android browser and a desktop browser.
